# Task Manager

Task Manager is a full-stack task management application built with React and Vite on the frontend, and Node.js, Express, Prisma, and PostgreSQL on the backend.

The application provides JWT-based user authentication and allows users to create, view, update, and delete their personal tasks.

## Technologies

- React
- Vite
- Node.js
- Express
- Prisma
- PostgreSQL
- JSON Web Tokens (JWT)
